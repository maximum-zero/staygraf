> **Date**: 2026-08-21

## Match Rate: 97%

세 번째 개선 반복에서 인쇄 열 너비 복원, 콘텐츠 기반 가변 행, 규격·옵션 2줄 압축, 추가 상품의 가짜 옵션 제거, 표 내부 배송 그룹 제거를 반영했다. 장바구니 선택부터 발행·이력·A4 PDF까지 핵심 흐름이 코드와 실제 Chromium 검증에서 일치했다. 남은 범위는 Safari·Android 저장과 15·30개 품목의 다중 페이지 실기기 출력 검증이다.

## 남은 검증 항목

- [ ] iPhone Safari 공유 메뉴에서 PDF·파일 저장 수동 확인
- [ ] Android Chrome 시스템 인쇄에서 PDF 저장 수동 확인
- [ ] 실제 15·30개 본품과 추가 상품 5개 조합의 다중 페이지 실기기 출력 확인

현재 인쇄 CSS는 열 머리글 반복, 품목 행·합계·조건의 페이지 분할 방지를 구현했다. 2페이지 이후 견적번호·수신처·페이지 번호의 정밀 반복은 서버 PDF 범위로 남겼다. 남은 항목은 브라우저·운영체제별 출력 검증이며 현재 화면 승인 차단 결함은 아니다.

## 설계 대비 변경

- 설계의 `QuotationLineCards` 별도 컴포넌트 대신 동일 semantic table을 모바일 CSS에서 세로 문서 행으로 재배치했다. 중복 마크업 없이 화면과 인쇄의 데이터·접근성 원본을 하나로 유지한다.
- `QuotationProgress`, 수신 폼, 요약, 대화상자는 Starter 수준에서 별도 파일로 과분리하지 않고 페이지 파일의 작은 하위 컴포넌트로 유지했다.
- 발행 결과 union의 네트워크 모의 계층은 만들지 않고 현재 로컬 검증 분기를 페이지에서 처리했다. 실제 API 연결 시 repository 경계에서 결과 타입을 추가한다.

## 결론

Match Rate가 90%를 넘고 P0 결함이 없다. 두 번째 개선 반복까지 승인된 MVP 범위의 구현은 완료됐으며 Report 단계로 전환할 수 있다.
