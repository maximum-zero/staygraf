## 요약

장바구니의 선택 묶음을 모의 로그인 이후 주문서로 전달하고 카드 또는 무통장입금 주문 스냅샷으로 생성하는 전체 사용자 여정을 구현했다. 실제 인증·PG·서버 API는 연결하지 않았으며 향후 API로 교체할 수 있도록 인증, 초안, 현재 상품 검증과 주문 저장 책임을 분리했다.

- 장바구니 선택 묶음 주문 진입

- 24시간 주문 초안·7일 주문 스냅샷
- 주문자·수령·주소·배송 요청 조건부 폼
- 신용·체크카드·무통장입금 모의 처리
- 상품·옵션·규격·추가 상품·가격·배송 제출 직전 재검증
- 상품·추가 상품 공급가액·부가세 스냅샷
- 선불 배송비 합산·착불 제외·직접 수령 0원
- 중복 제출 방지와 주문 대상 장바구니만 제거
- 카드 결제 완료·무통장 입금 대기 완료 화면
- 데스크톱 sticky 요약·태블릿 일반 흐름·모바일 fixed 결제 바
- 오류 인접 안내·첫 오류 포커스·44px target·reduced motion

## 유지할 결정

- 주문서에서는 상품 구성을 수정하지 않고 장바구니로 되돌린다.
- 주문 금액은 현재 카탈로그로 다시 계산하고 주문 생성 시점 이후에는 스냅샷을 사용한다.
- 결제 화면은 기존 STAYGRAF의 Pretendard·그린·중립 표면·절제된 선 체계를 유지한다.
- 모바일 결제 행동은 safe area를 포함한 하단 바에서 제공하되 상세 요약은 본문에 유지한다.

## 후속 범위

- 배송지 주소록과 공식 주소 검색은 후속 `shipping-address-ui` 기능으로 구현 완료
- 실제 회원 인증과 주문 API
- 실제 PG·무통장 계좌 정책
- 주문 목록·상세·취소·교환·환불
- 견적서 정보 입력·발행
- 무통장입금과 화물 배송 주소 제출의 독립 E2E 보강
