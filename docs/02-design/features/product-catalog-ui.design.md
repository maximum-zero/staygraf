# STAYGRAF 상품 탐색 UI - Design Document

> Version: 1.0.0 | Date: 2026-08-10 | Status: Approved
> Level: Starter | Plan: [product-catalog-ui.plan.md](../../01-plan/features/product-catalog-ui.plan.md)

---

## 1. Overview

이 문서는 STAYGRAF의 상품 목록·필터와 상품 상세 화면을 브라우저에서 검증하기 위한 UI 설계를 정의한다. 첫 검증 카테고리는 `타일`이며 2depth `타일 / 빅슬랩`을 제공한다. 사용자 승인 전에는 API, ERD와 관리자 속성 편집 구조를 확정하지 않는다.

## 2. Screen Inventory

### 2.1 Product List

- 기본 목록
- 2depth 전환 결과
- 필터가 적용된 목록
- 데스크톱 필터 사이드 패널
- 모바일 필터 바텀시트
- 정렬 메뉴
- 로딩 스켈레톤
- 빈 결과

### 2.2 Product Detail

- 구매 가능 상품
- 가격 문의 상품
- 품절 상품
- 옵션 선택 상태
- 타일 면적 계산기
- 배송 방식 선택
- 관련 GRAF

## 3. Navigation and Routes

```text
Header SHOP
├── /shop/tile?type=tile       타일 > 타일
├── /shop/tile?type=big-slab   타일 > 빅슬랩
├── /shop/faucet               수전
└── /shop/lighting             조명

Product list -> /products/{slug}
Product detail -> cart | buy | price inquiry | related GRAF
```

- 전체 상품 목록 경로는 제공하지 않는다.
- `SHOP`은 카테고리를 드러내는 탐색 트리거이며 사용자는 최소 1depth를 선택해 목록으로 이동한다.
- 필터와 정렬은 목록 URL에 직렬화한다.
- 옵션 기반 필터로 진입한 경우 일치 옵션을 상품 상세의 초기 선택값으로 전달한다.

### 4.4 Visual Hierarchy

- 목록 상단은 `현재 카테고리 경로 → 결과·필터·정렬 → 적용 조건 → 상품` 순서로 구성한다.
- 큰 시각적 H1은 두지 않고 스크린리더용 H1과 동일 크기의 브레드크럼으로 현재 위치를 제공한다.
- 넓은 데스크톱의 좌측 레일은 현재 1depth만 펼치며 활성 2depth를 브랜드 색상과 왼쪽 선으로 표시한다.
- 결과 개수는 13px 보조 정보, 필터·정렬은 최소 44px 조작 영역으로 제공한다.
- 적용 조건은 36px 칩으로 결과 행 아래에 노출하고 상품 그리드와 24px 간격을 둔다.
- 모바일 상품명과 가격은 14px을 기준으로 하며 상품 카드는 한 열로 제공한다.

## 5. Filter Model

### 5.1 Filter Layers

1. `1depth`: 타일
2. `2depth`: 타일 / 빅슬랩
3. `공통 필터`: 브랜드, 색상, 가격 방식
4. `타일 전용 필터`: 스타일, 용도, 규격, 패턴, 표면
5. `빅슬랩 전용 필터`: 용도, 규격, 두께, 패턴, 표면
6. `옵션 기반 필터`: 색상, 규격, 마감처럼 옵션에 따라 달라지는 속성

### 5.4 Filter Panel UI

- 데스크톱 측면 패널과 모바일 바텀시트는 동일한 필터 그룹 순서를 사용한다.
- 각 그룹은 다중 확장 가능한 아코디언이며 처음에는 `규격`만 펼친다.
- 선택된 그룹은 우측에 선택 개수를 표시하고 옵션은 GRAF와 같은 pill 선택 상태를 사용한다.
- 반복 구분선은 제거하고 기술 조건, 디자인 조건, 구매 조건 사이에만 두 개의 구분선을 사용한다.
- 하단에는 `초기화`와 `N개 상품 보기`를 고정한다.

### 5.5 Deferred Filters

- 원산지
- 실내·실외
- 공간 추천(거실·주방·욕실 등)
- 미끄럼 저항 등급
- 흡수율과 내마모 등급
- 재고·당일 출고
- 배송 방식
- GRAF 연결 여부

위 항목은 실제 데이터의 신뢰도와 사용자 요구를 확인한 뒤 추가한다. 목록 필터에 없더라도 상품 상세의 규격표에는 제공할 수 있다.

### 5.5 Filter Interaction

- 필터 버튼은 적용된 조건 수를 숫자로 표시한다.
- 데스크톱 패널과 모바일 시트는 적용 버튼을 누를 때 URL과 결과를 갱신하는 방식을 우선한다.
- 패널 안에서 변경 중인 임시 조건과 적용된 URL 조건을 분리한다.
- 적용 조건은 결과 행 아래 가로 칩으로 노출한다.
- 개별 칩 해제는 즉시 결과에 반영한다.
- `초기화`는 2depth 카테고리와 정렬을 유지하고 속성 필터만 제거한다.
- 같은 그룹은 다중 선택 OR, 다른 그룹은 AND로 결합한다.
- 선택지별 결과 개수는 초기 샘플 데이터가 충분할 때만 노출한다.
- 데스크톱 필터는 화면 오른쪽에서 열리는 약 420px 고정 패널로 제공한다.
- 패널이 열린 동안 목록은 약한 오버레이 아래에 유지하고 배경 조작과 스크롤을 막는다.
- 필터 그룹만 스크롤하며 하단의 `초기화 / N개 상품 보기` 영역은 고정한다.
- 767px 이하는 전체 폭, 768~1023px은 최대 640px 중앙 바텀시트로 제공한다.

## 6. Sort

초기 정렬은 다음으로 제한한다.

- 추천순: 운영 순서 필드가 준비되기 전에는 기본 등록 순서
- 신상품순: 등록일 내림차순
- 낮은 가격순
- 높은 가격순

가격 문의 상품은 가격 정렬의 뒤에 배치한다. 인기순, 판매순과 리뷰순은 근거 데이터가 생기기 전 제공하지 않는다.

## 7. Product Card

```text
┌────────────────────────┐
│ [상태 배지]            │
│                        │
│      대표 이미지       │
│                        │
├────────────────────────┤
│ [옵션][옵션][옵션][옵션][+2]│
│ BRAND · COLLECTION     │
│ 상품명                 │
│ 74,000원 ~ 92,000원    │
└────────────────────────┘
```

- 정보 순서는 브랜드·컬렉션 → 상품명 → 가격이다.
- 모든 상품은 옵션을 최소 하나 이상 가지며 이미지 바로 아래 한 행을 다섯 슬롯으로 사용한다.
- 옵션이 다섯 개 이하면 모두 표시하고, 여섯 개 이상이면 대표 썸네일 네 개와 `+N`을 표시한다.
- 상품 커버는 선택값이며 지정되지 않으면 `defaultOptionId`가 가리키는 옵션 대표 미디어를 목록 기본 이미지로 사용한다.
- 각 옵션은 미디어를 최소 하나 이상 가지며 그중 하나를 대표 미디어로 지정한다.
- 옵션 선택은 카드 대표 이미지만 변경하고 가격은 상품 범위를 유지한다.
- 옵션이 없는 상품 데이터는 허용하지 않으며 목록 카드의 옵션 행은 항상 제공한다.
- 카드 전체가 상세 링크이며 옵션 버튼은 링크 동작과 분리한다.
- 배송, VAT, BOX, 규격과 찜 버튼은 카드에 노출하지 않는다.
- 가격 문의는 버튼이나 강조색 없이 가격 위치에 표시한다.
- 배지는 `NEW` 또는 `MD PICK`만 데이터 근거가 있을 때 카드당 하나만 노출한다.
- 정사각 이미지가 카드의 가장 강한 요소가 되며 카드 가로 간격은 18~22px, 세로 간격은 40~44px을 기준으로 한다.
- 브랜드·컬렉션은 12px 보조색, 상품명은 데스크톱 15px·모바일 14px/600, 가격은 14px/700을 기준으로 한다.
- 상품명은 최대 한 줄 말줄임을 적용하고 전체 이름은 접근 가능한 제목 정보로 제공한다.
- 상품명에 강제 높이를 두지 않으며 모든 카드에 필수 옵션 행을 동일하게 제공한다.

## 8. Product Detail Structure

상세 정보 위계는 다음 순서로 설계한다.

1. 갤러리
2. 브랜드·컬렉션과 상품명
3. 가격 방식과 판매 상태
4. 옵션 선택
5. 핵심 규격·포장 정보
6. 면적 계산기(타일·빅슬랩)
7. 수량과 배송 방식
8. 장바구니·바로 구매 또는 가격 문의
9. 상세 설명과 전체 규격표
10. 관련 GRAF

데스크톱은 좌측 갤러리와 우측 구매 정보의 2열, 모바일은 갤러리부터 세로로 쌓고 구매 행동을 하단 고정 영역으로 제공하는 방안을 비교한다.

## 9. Loading, Empty and Error States

- 첫 목록 진입은 카드 이미지 비율과 텍스트 행을 예약한 스켈레톤을 사용한다.
- 필터 적용 중에는 기존 결과를 유지하고 결과 영역에 낮은 강도의 진행 상태를 제공한다.
- 빈 결과는 적용 조건을 보여주고 `초기화`를 제공한다.
- 이미지 로드 실패 시 상품명을 포함한 대체 영역을 제공한다.
- URL에 유효하지 않은 필터가 있으면 무시하고 유효한 조건만 복원한다.

## 10. Accessibility and Motion

- 필터 패널·시트는 포커스 이동·순환·복귀, Escape 닫기와 배경 비활성화를 지원한다.
- 필터 결과 개수는 `aria-live="polite"`로 알리되 연속 조작 중 중복 알림을 줄인다.
- 옵션 썸네일은 최소 44px 터치 영역과 선택 이름, `aria-pressed`를 제공한다.
- 색상 선택에는 색상칩과 텍스트 이름을 함께 제공한다.
- 패널과 시트 전환은 180~240ms, 옵션 이미지 전환은 150~200ms로 제한한다.
- 상품 카드 재배치에는 장식적 애니메이션을 적용하지 않는다.
- `prefers-reduced-motion`에서 비필수 전환을 제거한다.

## 12. State Responsibility

| State | Responsibility |
|---|---|
| 1·2depth, filter, sort | URL Search Params |
| 패널 안 미적용 조건 | React local state |
| 카드 옵션 이미지 | ProductCard local state, 상세 진입 시 `option` Search Param |
| 상세 선택 옵션·갤러리·계산기 | `option` Search Param 초기값 + Product detail local state |
| 비회원 장바구니 | Zustand persist, 후속 단계 |
| 서버 상품·재고 | 미도입, 백엔드 설계 후 결정 |

## 13. Validation Scenarios

- 타일과 빅슬랩을 전환하면 해당 필터 정의와 결과가 복원된다.
- 여러 필터 그룹을 적용하고 URL을 공유하면 동일한 상품과 적용 칩이 표시된다.
- 옵션 기반 필터 결과의 카드 이미지와 상세 초기 옵션이 일치한다.
- 목록에서 옵션을 선택한 뒤 상세에 진입하면 동일한 옵션과 옵션 미디어 갤러리가 처음부터 선택된다.
- 가격 문의 상품은 가격 정렬과 구매 행동에서 일반 상품과 구분된다.
- 모바일에서 필터 적용·해제·초기화 후 원래 스크롤 위치로 복귀한다.
- 320, 375, 414, 479, 480, 539, 540, 620, 621, 767, 768, 1023, 1024, 1239, 1240과 1440px에서 가로 넘침과 비정상 열 전환이 없다.
